## Активация учётки (два варианта)

### Вариант А — Консольный seed (без Bitrix, мгновенно)

Открыть https://kinspon8.github.io/axoft-accelerator/ в браузере,
открыть DevTools (F12) → Console и вставить:

```javascript
localStorage.setItem('axoft_vendor_session', JSON.stringify({
  leadId: null,
  email: 'test@axoft-vendor.ru',
  company: 'ООО Axoft Test',
  inn: '7712345671',
  direction: 'ИИ — ML/AI для B2B',
  stage: 'Стартап (до 3 лет), есть MVP',
  skolkovo: true,
  tier: 'strat',
  registeredAt: '2026-06-09T12:00:00.000Z',
  _h: 'f7c2bc942a1c9352f2b510a6e0c95a5fdb515d2991169c026d5b8d0098826049'
}));
location.href = 'cabinet.html';
```

После выполнения открывается кабинет под тестовой учёткой.

### Вариант Б — Регистрация через форму (с Bitrix)

1. Открыть https://kinspon8.github.io/axoft-accelerator/
2. Вкладка «Регистрация», заполнить данные из таблицы выше
3. Нажать «Зарегистрировать компанию»

При успехе в Bitrix24 CRM появится лид `Новый вендор: ООО Axoft Test`
и запись в списке вендоров (список ID=131).

## Чеклист тестирования

### Авторизация
- [ ] Регистрация новой компании (вариант Б)
- [ ] Повторная регистрация с тем же email → должна быть ошибка
- [ ] Неверный ИНН (не 10 цифр) → ошибка валидации
- [ ] ИНН с неверной контрольной суммой → ошибка
- [ ] Несовпадающие пароли → ошибка
- [ ] Вход с правильными данными
- [ ] Вход с неверным паролем → ошибка
- [ ] Выход из кабинета → редирект на index.html
- [ ] Повторное открытие cabinet.html без сессии → редирект на index.html
- [ ] Сброс пароля: «Забыл пароль?» → форма → ссылка → новый пароль → вход

### Дашборд
- [ ] Аватар (инициалы) и название компании отображаются в сайдбаре
- [ ] Аватар и название в topbar
- [ ] Приветственная строка: «Добро пожаловать, ООО Axoft Test!»
- [ ] Статус тарифа UP STRAT отображается корректно
- [ ] Шаги прогресса (4 шага)

### Сервисы — Пакеты
- [ ] Пакеты грузятся из Bitrix24 (список 123) или fallback данные
- [ ] Отображаются карточки всех пакетов
- [ ] Кнопка «Заказать» / «Подключить» — оформляет сделку
- [ ] После оформления → toast «Заказ оформлен»
- [ ] Кнопка не активна повторно после нажатия

### Сервисы — Партнёрская программа
- [ ] Вкладка открывается
- [ ] Таблица сравнения пакетов отображается
- [ ] На мобильном — таблица с горизонтальным скроллом

### Сервисы — Услуги à la carte
- [ ] Список услуг грузится из Bitrix24 (список 127)
- [ ] Фильтрация по блокам работает
- [ ] Кнопка «Запросить» создаёт лид-запрос в Bitrix

### Заказы
- [ ] Список заказов пустой при старте (вариант А)
- [ ] После заказа сервиса — заказ появляется в списке
- [ ] Статусы синхронизируются с Bitrix24 при перезагрузке страницы
- [ ] Ссылка на сделку в Bitrix работает (если есть bitrixDealId)
- [ ] Кнопка «Перейти в каталог» из пустого экрана работает

### Материалы
- [ ] Список материалов грузится из Bitrix24 (список 125)
- [ ] Категории материалов отображаются
- [ ] Кнопка «Скачать» или «Открыть» ведёт на файл
- [ ] Некорректные URL файлов не показываются

### Диагностика
- [ ] Стартовый экран с шагами → кнопка «Начать оценку»
- [ ] Навигация по категориям (вкладки)
- [ ] Ответы на вопросы записываются
- [ ] Шкала прогресса обновляется
- [ ] Результат: итоговый балл + рекомендации

### Настройки
- [ ] Поля компании заполнены из сессии (название, ИНН, email, etc.)
- [ ] Дата регистрации корректная
- [ ] Нет полей ФИО / личный телефон (данные только юрлица)

### Мобильная адаптация (≤600px)
- [ ] Дашборд: шаги 2×2, стат 2 колонки
- [ ] Настройки: метки над значениями (не рядом)
- [ ] Сервисы: вкладки скролятся горизонтально
- [ ] Партнёрка: таблица сравнения с горизонтальным скроллом
- [ ] Заказы: скрыта колонка «Оплата», таблица скролится
- [ ] Диагностика: шаги 1 колонка, категории скролятся
