# UP: Axoft × Сколково — Лендинг

Страница-заглушка на GitHub Pages. Один HTML-файл, без фреймворков и сборки.

**Live:** https://kinsposan.github.io/axoft-accelerator/landing/

---

## Быстрый старт

```bash
python3 -m http.server 8765 --directory landing/
# → http://localhost:8765
```

---

## Структура

```
landing/
├── index.html        ← весь лендинг (HTML + CSS + JS в одном файле)
├── logos/
│   ├── axoft.png
│   └── skolkovo.png
└── README.md
```

Всё — в `index.html`. Секции в файле идут в таком порядке:
1. `<head>` — мета, шрифты, CSS-переменные, стили
2. `<!-- HEADER -->` — шапка с логотипами и бейджем даты
3. `<!-- HERO -->` — заголовок, таймер обратного отсчёта, форма email
4. `<!-- BENEFITS -->` — карточки «Что даёт программа»
5. `<!-- PARTNER STRIP -->` — блок «Партнёр: Axoft» со статистикой
6. `<!-- DIRECTIONS -->` — карточки направлений отбора
7. `<!-- TIMELINE -->` — график программы (4 этапа)
8. `<!-- FOOTER -->` — подвал
9. `<script>` — таймер + логика формы email

## Ключевые параметры

### Дата открытия регистрации

Меняется в 4 местах `index.html`:

| Что | Как найти | Пример |
|-----|-----------|--------|
| Таймер (JS) | `const TARGET = new Date(` | `'2026-06-22T00:00:00'` |
| Шапка | `class="header-badge"` | текст внутри тега |
| Подпись под таймером | `class="countdown-note"` | текст внутри тега |
| Первый этап таймлайна | `class="tl-label"` (первый) | текст внутри тега |

### Форма сбора email

В конце `<script>` найди константу:

```js
const LEADS_ENDPOINT = '';
```

Подставь URL, куда отправлять `POST { email, source: 'landing', ts }`:

| Сервис | URL |
|--------|-----|
| **Formspree** | `https://formspree.io/f/<form-id>` (бесплатно до 50/мес) |
| **n8n webhook** | URL вебхука из workflow n8n |
| **Bitrix24** | собственный прокси (прямой вызов `crm.lead.add` из браузера не подходит — токен будет виден) |

Если `LEADS_ENDPOINT` пустой — адрес сохраняется только в `localStorage` браузера под ключом `up_leads` (массив строк). Данные не теряются при обновлении, но привязаны к конкретному устройству.

## Брендбук Axoft 2025

### Цвета

```css
--navy:  #1e2849  /* тёмно-синий, основной фон и текст */
--green: #00b27c  /* зелёный, иконки и акценты вне hero */
--teal:  #00b0bd  /* бирюзовый, hero-акценты (лучше контраст на тёмном) */
--blue:  #00adef  /* голубой */
--soft:  #f6f6f6  /* светло-серый, фон секций */
```

### Шрифт

**Roboto** — официальный веб-шрифт Axoft. Подключён из Google Fonts, веса 300 / 400 / 500 / 700.

## Деплой

Автоматически при пуше в `main` через GitHub Actions (`.github/workflows/deploy.yml`).

Workflow использует `actions/deploy-pages`. В настройках репозитория:
**Settings → Pages → Source → GitHub Actions**

Время деплоя: ~1–2 мин после мержа в `main`.
